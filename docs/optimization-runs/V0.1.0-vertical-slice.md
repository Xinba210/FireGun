## 一、執行流程：概念圖 → 3D 建模 → 引擎實機渲染 → 固定視角 A/B → 問題評估 → 修正 → 性能測試 → 再次驗收

### 1. 第一輪（Cycle 1）實機渲染與問題評估

在完成初始 3D 港口環境 (`port_environment.glb`)、武器包 (`weapons_pack.glb`) 與 65 骨骼 CC0 士兵 (`soldier_tactical_animated.glb`) 後，以固定參考鏡位 `cam_hero`（Pitch 26° 俯角）與 `cam_lane`（1.75m 玩家視角）進行第一輪實機渲染（保存為 `docs/evidence/v0.1.0/cam_hero_before.png` 與 `cam_lane_before.png`），發現以下三項核心問題：

1. **PBR 金屬材質於夜間無環境貼圖 (IBL) 下過暗**：
   - 貨櫃波浪鋼板、起重機鋼樑與槍枝護木設定了較高 `metallic`（0.70–0.88），但場景僅有直接光源而無 `scene.environment` PMREM 環境反射貼圖，導致金屬表面吸收漫反射光而呈現偏黑剪影。
2. **士兵網格雙重疊加導致三角形數量偏高（277,664 Tris）與頂點色干擾**：
   - 將 Quaternius `Male_Ranger_*` 戰術裝備網格移植至 `UAL1_Standard.glb` 65 骨骼時，同時保留了 `UAL1` 原始的 `Mannequin` 素體且帶有橘白色 `COLOR_0` 頂點色屬性，不僅造成局部破面，更使 8 名敵人同時在場時場景總三角形數高達 **277,664 Tris**。
3. **3D 武器庫檢視 (Loadout Inspection) 缺乏獨立補光**：
   - 在倉庫或陰影處開啟 `[L]` 武器檢視介面時，槍枝模型僅依賴環境光，表面法線紋理不夠清晰。

### 2. 第二輪（Cycle 2）針對性修正內容

1. **建立程序化夜間港口 PMREM 環境反射貼圖 (`PMREMGenerator`) 與光影校正**：
   - 於 `src/main.ts` 使用 `THREE.PMREMGenerator` 建立具備深藍夜空天頂、高壓鈉燈暖橘光斑、海面微光與濕地反光的即時 IBL 環境貼圖（`scene.environment = envMap`），並適度提升高壓鈉燈與月光填充強度。
2. **移除冗餘 `Mannequin` 素體與 `COLOR_0` 頂點色，場景三角形減少 40%（士兵網格減少 55%）**：
   - 修改 `tools/build_assets_glb.mjs`，直接以 `Male_Ranger_*` 65 骨骼戰術網格替換 `UAL1` 素體，並清除 `COLOR_0` 頂點色，使單一士兵模型更乾淨、無雙層 Z-fighting，整體場景三角形由 **277,664** 大幅降至 **166,000–167,580**。
3. **新增 Loadout 3D 武器檢視雙點主輔燈 (`loadoutKeyLight` + `loadoutRimLight`)**：
   - 為 3D 武器旋轉檢視台加入專屬冷白主光與暖金輪廓光，清楚呈現 `SR-9 スナイパー`、`AR-7 カービン` 與 `RL-7 ロケット` 的 PBR 金屬拉絲與戰術導軌細節。

### 3. 第三輪（Cycle 3 / v0.2.0）場景細節與寫實度全面升級

針對同鏡位 A/B 比對圖（`ab_comparison_hero.png`、`ab_comparison_lane.png`）的視覺差距，執行六大面向深化：
1. **多八度 FBM 程序化 PBR 貼圖重構**：升級 `wet_concrete`（連續平滑濕地法線過渡與微裂縫）、`container_red/blue/green`（梯形波浪鋼板法線、邊角剝落與垂直水痕）、`rusted_steel`（深冷鋼底色搭配局部邊緣鏽蝕，消除塊狀迷彩感）、`wood_crate`（軍用深木紋與金屬包角）與 `tactical_camo`（深色夜戰迷彩裝甲）。
2. **補齊概念圖關鍵戰術載具與港區重工道具**：新增 2 輛停放於東側倉庫外的戰術裝甲車 (`Tactical Armored Humvee / LTV`)、西側碼頭堆高機 (`Forklift`)、木製電纜捲軸 (`Cable Reels`)、木棧板堆 (`Pallets`)、岸壁防撞橡膠護舷 (`Rubber Fenders`)、懸垂泊船鐵鍊 (`Catenary Chains`)、傾倒鐵桶與安檢哨升降柵欄。
3. **建築與大型結構幾何升級**：東側倉庫改為雙斜脊屋頂 (`Pitched Gable Roof`) 搭配採光天窗、室內鋼桁架與外牆冷氣機組；龍門起重機加入交叉斜撐桁架 (`X-Bracing`)、斜拉鋼索與吊具 (`Spreader`)；貨輪加入前傾船首、繫船纜繩與艦橋探照燈。
4. **自訂 Shader 與夜間降雨粒子特效**：將高桿鈉燈硬邊圓錐替換為具備 Fresnel 邊緣衰減的 `ShaderMaterial` 體積光束；火桶加入多層動態搖曳火焰 Shader 與 120 顆上升火星粒子 (`THREE.Points`)；全場景加入單一 Draw Call 的 750 道夜間斜雨線條 (`THREE.LineSegments`)。
5. **敵軍夜戰特戰塗裝**：將 65 骨骼士兵改為深灰藍夜戰迷彩、碳黑防彈背心與微光戰術護目鏡。
